# Инструкция по развёртыванию бэкенда Supabase

Данный проект мини-CRM использует Supabase (PostgreSQL + Auth + Row Level Security + Triggers).

## Шаг 1: Создание проекта в Supabase
1. Перейдите на [supabase.com](https://supabase.com) и войдите в аккаунт.
2. Создайте новый проект (бесплатного тарифа Free Tier достаточно).
3. Дождитесь готовности базы данных (1-2 минуты).

## Шаг 2: Применение структуры базы данных (Schema)
1. В панели управления Supabase откройте раздел **SQL Editor**.
2. Скопируйте всё содержимое файла `supabase/schema.sql` и вставьте в окно SQL Editor.
3. Нажмите кнопку **Run** (Выполнить).
   - Будут созданы таблицы: `profiles`, `objects`, `tasks`, `task_history`.
   - Будет включен Row Level Security (RLS) на всех 4 таблицах.
   - Будут настроены триггеры проверки переходов статусов и защиты истории.
   - Будет создана функция `change_task_status(...)`.

## Шаг 3: Наполнение тестовыми пользователями и данными (Seed)
1. В **SQL Editor** создайте новый запрос.
2. Скопируйте содержимое файла `supabase/seed.sql` и вставьте в редактор.
3. Нажмите кнопку **Run** (Выполнить).
   - Будут созданы 4 пользователя с паролем `Password123!`:
     - `manager1@crm.local` (Постановщик: Алексей Смирнов)
     - `manager2@crm.local` (Постановщик: Иван Кузнецов)
     - `worker1@crm.local` (Исполнитель: Дмитрий Новиков)
     - `worker2@crm.local` (Исполнитель: Сергей Васильев)
   - Будут созданы 4 строительных объекта.
   - Будут созданы тестовые задачи во всех 5 статусах с полной историей.

## Шаг 4: Отключение открытой регистрации (Требование ТЗ 3)
1. В левом меню Supabase перейдите в **Authentication** -> **Providers** -> **Email**.
2. Снимите флажок **"Enable Signup"** (Разрешить регистрацию).
3. Нажмите **Save**. Теперь открытая регистрация заблокирована, пользователи добавляются только административно.

## Шаг 5: Подключение к фронтенду
1. В настройках проекта Supabase перейдите в **Project Settings** -> **API**.
2. Скопируйте:
   - **Project URL**
   - **anon public key**
3. В корне проекта `mini-CRM` создайте файл `.env`:
   ```env
   VITE_SUPABASE_URL=https://ваш-проект.supabase.co
   VITE_SUPABASE_ANON_KEY=ваш_anon_публичный_ключ
   ```
4. Запустите фронтенд: `npm run dev`.
